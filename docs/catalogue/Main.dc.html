Comment lire une planche. En haut, la règle et le composant à utiliser. Puis les états figés côte à côte (repos, survol, focus clavier, désactivé…) : seuls les états qui existent dans le code sont montrés. En pointillés, un exemplaire vivant à survoler et cliquer ; « Rejouer » relance les animations. Le style vient du CSS compilé de l'application, pas d'une copie. Le catalogue tient sur neuf planches : liens en haut de chacune.
