En-tête de bloc et visibilité

EntityBlocks.tsx · shared/EyeIcon.tsx · visibilityOptions.ts

Chaque bloc d'une fiche : poignée ⠿ pour glisser, ▾ pour replier (pivote de −90° à la fermeture), titre en Outfit éditable, type, état d'enregistrement, pilule de visibilité, ▲▼, menu ⋮. Pour un élément isolé (souvenir, nœud d'arbre, calque de carte), la visibilité est un œil ouvert / barré.

Mouvement : ▾ : rotation, 150 ms (transition-transform) ; reste : couleurs, 150 ms, cubic-bezier(0.4, 0, 0.2, 1) (transition-colors)
